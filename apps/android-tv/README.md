# Momento — Android / Google TV

A real Daydream screensaver (`android.service.dreams.DreamService`) that
hosts the shared web rendering engine (`../tv-app`) in a `WebView`. This is
the current primary target — see `docs/ARCHITECTURE.md` §1/§5.7 for why.

## Prerequisites

- Android Studio (any recent version) — used for its JDK and, if you
  prefer a GUI, for opening/running this project directly.
- Node/npm on `PATH` — the build automatically runs `npm run build` in
  `../tv-app` and copies the output into `app/src/main/assets/web`.
- The Android SDK command-line tools, a Google TV system image, and an AVD.
  If you haven't set these up yet:

  ```bash
  # 1. Download & unpack the command-line tools into the SDK location
  #    Android Studio expects (~/Library/Android/sdk on macOS), nested
  #    under cmdline-tools/latest — see Google's SDK command-line tools
  #    download page for the current URL for your OS.

  export ANDROID_HOME="$HOME/Library/Android/sdk"
  export PATH="$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$PATH"

  yes | sdkmanager --licenses
  sdkmanager "platform-tools" "emulator" "platforms;android-36" \
    "build-tools;36.1.0" "system-images;android-36;google-tv;arm64-v8a"

  avdmanager create avd -n Momento_GoogleTV \
    -k "system-images;android-36;google-tv;arm64-v8a" --device "tv_1080p"
  ```

  Use `arm64-v8a` on Apple Silicon Macs (and Windows/Linux ARM) for a
  native, fast emulator; use `x86_64` on Intel machines.

## Running the emulator

```bash
export ANDROID_HOME="$HOME/Library/Android/sdk"
export PATH="$ANDROID_HOME/emulator:$ANDROID_HOME/platform-tools:$PATH"
emulator -avd Momento_GoogleTV &
adb wait-for-device
```

The emulator boots straight into Google TV's "Set up Google TV" account
flow. For quick iteration you don't need to complete it — see the note
below on Settings gating.

## Build & install

```bash
export ANDROID_HOME="$HOME/Library/Android/sdk"
./gradlew :app:installDebug
adb shell am start -n com.momento.tv/.MainActivity
```

From `MainActivity`, press **Preview** to see the full-screen wall
immediately (this is the fast dev loop — see below) or **Open Screen Saver
Settings** to jump to the system picker.

## ⚠️ A real limitation found while building this, worth knowing

Google TV's Settings → System → **Ambient Screensaver** picker reports
"Unavailable — please set up Google TV" until the emulator's account setup
is fully completed (a real Google sign-in). Current Google TV emulator
system images also ship as locked-down `user` builds (no `adb root`), so
the `adb shell cmd dreams start-dreaming` shortcut some older guides
mention isn't available as a workaround either.

None of this is a problem with Momento's registration (the manifest/dream
XML pattern is the standard, correct one — see `MomentoDreamService.kt`
and `res/xml/momento_dream_info.xml`) — it's just that this specific dev
loop is gated behind account setup. Two ways to actually see it running as
the *real* system screensaver:
1. Sign into a real Google account in the emulator (or on a physical
   Chromecast with Google TV / Google TV device) and select Momento from
   Settings → System → Ambient Screensaver.
2. In the meantime, use the in-app **Preview** button — it renders through
   the exact same `WebEngineHost` code path the Dream itself uses, which is
   what was actually used to verify the WebView + asset-loading integration
   end-to-end while building this.

## Project structure

```
app/src/main/java/com/momento/tv/
  MomentoDreamService.kt   the real screensaver (DreamService)
  WebEngineHost.kt         shared WebView + WebViewAssetLoader setup
  MainActivity.kt          launcher screen: Preview / Open Settings
  PreviewActivity.kt        full-screen in-app preview
app/src/main/res/xml/momento_dream_info.xml   Dream metadata (settings activity link)
app/src/main/assets/web/   built ../tv-app output (regenerated by Gradle; gitignored)
```

## Regenerating web engine assets only

```bash
./gradlew :app:syncWebEngineAssets
```
